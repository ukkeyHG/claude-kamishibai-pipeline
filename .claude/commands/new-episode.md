# 自動エピソード生成パイプライン

県名（日本語）: **$ARGUMENTS**

## 実行

Pythonオーケストレーターを起動して、新エピソードを自動生成する。

```bash
python -m orchestrator.main "$ARGUMENTS"
```

オプション:
- `--resume`: 中断したrunを再開
- `--verbose`: デバッグログ出力

## 注意点

- クラウドコードが起動している cwd で実行すること
- プロジェクトルート（series_bible.md と .claude/ がある場所）で実行すること
- 処理はバックグラウンドで数十分かかることがある
- 中断した場合は `--resume` オプションで再開可能
